Brain Tumor Classification using Graph Attention Network v2 (GATv2) with Residual Connections for Stable and Explainable Learning

I developed and evaluated machine learning and deep learning models for image classification and medical diagnosis, focusing on interpretability and reliability. This work combines graph neural networks with Grad-CAM explainability to enhance transparency in medical image analysis. The medical images are transformed into graph representations, with image patches represented as nodes and spatial relationships represented through graph edges. I have experimented with GATv2-based graph neural networks, residual connections, batch normalization, dropout, graph pooling, and attention mechanisms. My interest extends beyond classification performance to understanding how the model arrives at its predictions through Grad-CAM. This research has motivated me to think critically about model reliability, explanation quality, and the relationship between computational representations and clinically meaningful information.
